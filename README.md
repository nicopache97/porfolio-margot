# Margot Castillo - Portfolio 2026

Este repositorio contiene el portafolio digital de **Jessica Margot Castillo**, también conocida, una diseñadora en comunicación visual especializada en branding y packaging.

## 🎨 Sobre Mar
Mar es una estudiante avanzada de Diseño en Comunicación Visual en la Facultad de Artes de la Universidad Nacional de La Plata (UNLP). Con raíces en la Patagonia y un profundo amor por la naturaleza, su enfoque se centra en la practicidad y la exploración de nuevas formas en el diseño de marcas y sistemas de empaque.

## Proyectos Destacados: "Ecosistema Buenos Mates"
El proyecto central de este portafolio es la propuesta integral de branding y packaging para **Buenos Mates**, que incluye diversas extensiones de línea:

- **Buenos Mates**: Identidad y empaque para yerba mate.
- **Buenos Alfajores**: Diseño de packaging para alfajores de algarroba.
- **Buenos Bocados**: Línea de snacks saludables.
- **Hierbas para el Mate**: Etiquetas y empaques para variedades como Peperina, Cedrón, Manzanilla, Burrito, Cola de Caballo y Tilo.

## 🛠️ Habilidades Técnicas
- **Software**: Adobe Illustrator (Ai), Adobe Photoshop (Ps).
- **Disciplinas**: Diseño de Identidad de Marca, Diseño de Packaging, Diseño Editorial.

## 💻 Stack Tecnológico (Web)
Este portafolio web está construido con tecnologías modernas:
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Estilos**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Componentes**: [shadcn/ui](https://ui.shadcn.com/)
- **Iconos**: Lucide React
- **Gráficos**: Recharts

## 🛠️ Cómo Iniciar el Proyecto
Este proyecto utiliza `pnpm`. Si no lo tienes instalado globalmente, puedes usar `npx`:

1.  **Instalar dependencias**:
    ```bash
    npx pnpm install
    ```

2.  **Iniciar el servidor de desarrollo**:
    ```bash
    npx pnpm dev
    ```
